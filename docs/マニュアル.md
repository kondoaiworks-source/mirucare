# 監査のミカタ 利用マニュアル

介護事業所向け「AI書類Wチェック」サービスです。  
介護ソフトから出力したCSV／PDFや、スマホで撮った写真をアップロードすると、実地指導（運営指導）で指摘されやすい不備を、根拠付きで確認できます。

> **本サービスはWチェック支援であり、最終判断・提出は貴施設の責任で行ってください。**  
> 「違反です」「不正です」といった断定は行いません。「〜の可能性があります」「〜をご確認ください」という形でお伝えします。  
>  
> **位置づけ：** 合否や返還を保証するツールではなく、**実務上の致命傷になりやすい矛盾・疑義を先に見つける予防装置**です。  
> 完成図の詳細は [プロダクト完成図.md](./プロダクト完成図.md) を参照してください。

## 1. はじめに

### できること

| 機能 | 内容 | 利用できるプラン |
|------|------|------------------|
| 書類チェック | PDF・CSV・Excel・写真をアップしてAIが確認 | ライト／スタンダード／プレミアム |
| 指摘の確認・対応 | 「対応した」「あとで」「これは違うと思う」 | 同上 |
| 期限アラート | 同意日・更新期限などの見落とし防止 | スタンダード／プレミアム |
| 勤怠・日報の取込 | 介護ソフトのCSVを事業所データへ取込 | 全プラン |
| 勤怠の矛盾検知 | 日報の時間重複・退勤とのズレの可能性を確認 | 全プラン |
| 請求CSV突合 | 国保連送信前CSVを日報と1分単位で照合（端末内のみ） | 全プラン |
| 月次レポート | 月ごとの指摘傾向と原因分析、PDF出力 | プレミアム |

### 想定ユーザー

訪問介護・通所介護などの事業所で、施設長やサービス提供責任者として書類確認をされる方を想定しています。スマートフォンでも操作できます。

### ご利用の注意

- 合否判定や返還リスクの保証は行いません
- チェック結果は「気になる点」の参考です。最終的な判断・行政への提出は貴施設で行ってください
- 介護記録は要配慮個人情報です。アカウント・パスワードは適切に管理してください

## 2. アカウント作成と初回設定

### 2-1. アカウントを作成する

1. 「アカウントを作成する」画面を開きます
2. **お名前**・**メールアドレス**・**パスワード**（8文字以上）を入力します
3. 作成後、初回設定（オンボーディング）へ進みます

すでにアカウントがある場合は「ログインする」から、メールアドレスとパスワードで入ってください。

### 2-2. 事業所を登録する（初回のみ・3ステップ）

| ステップ | 内容 |
|----------|------|
| ① 事業所を登録する | 事業所名・サービス種別などを入力します |
| ② 所在地の自治体を選ぶ | 運営指導の参考となる自治体を選びます |
| ③ 設定が完了しました | ダッシュボードへ進めます |

> 招待リンクから参加した場合は、事業所登録は不要です。既存の事業所にスタッフ（または管理者）として加わります。

## 4. 書類をチェックする（基本の流れ）

### 4-1. ダッシュボードから始める

1. ダッシュボードで **「今日の分をチェックする」** を押します  
   （書類一覧からも同じ操作ができます）
2. アップロード画面が開きます

### 4-2. ステップ1：書類をアップロードする

画面タイトル：**今日の書類をアップロード**

- ファイルをドラッグ＆ドロップするか、「選択する」でファイルを選びます
- スマホでは **「書類を撮影する」** からカメラ撮影もできます
- 複数ファイルを一度に上げられます（1ファイルあたり最大20MB）

**対応形式**

| 種類 | 拡張子の例 |
|------|------------|
| PDF | `.pdf` |
| 表計算・データ | `.csv` / `.xls` / `.xlsx` |
| 写真 | `.jpg` / `.jpeg` / `.png` / `.webp` / `.heic` / `.heif` |

アップロード中は進捗バーが表示されます。失敗した場合は **「再試行」** が使えます。

すべて上がったら **「種類の選択へ進む」** を押します。

### 4-3. ステップ2：書類の種類を選んで開始する

次のいずれかを選びます（AIが候補を示す場合、「候補」バッジが付きます）。

- ケアプラン
- 提供記録
- 勤務表
- 請求データ
- その他

**「チェックを開始する」** を押すと、AIチェックが始まります。

### 4-4. チェック中の表示

結果画面では、状況に応じて次のように表示されます。

| 表示 | 意味 |
|------|------|
| 書類を確認しています… | AIがチェック中です。しばらくお待ちください |
| 運営が結果を確認しています… | 公開前に人間レビュー中です（後述） |
| 気になる点が N件 ありました | 指摘があります。内容を確認してください |
| 今回は気になる点は見つかりませんでした | 0件です。見落としがないことを保証するものではありません |

### 4-5. 書類一覧の状態

**書類チェック** 画面では「今日の分」「過去の分」を切り替えられます。

| バッジ | 意味 |
|--------|------|
| 種類未設定 | アップロード済みだが種類未選択。一覧の「このアップロードを取り消す」で削除できる（完了ボタンでは消せない） |
| チェック中 | AIチェック進行中 |
| 確認待ち | 指摘への対応が残っている |
| 後で確認 | 「あとで」にした指摘がある |
| 完了 | 対応が終わっている |

## 5. 指摘への対応

チェック結果の各指摘カードでは、次の操作ができます。

| ボタン | 意味 |
|--------|------|
| **対応した** | 現場で確認・修正などの対応を終えた |
| **あとで** | 後で改めて確認する（「あとで確認」一覧に入ります） |
| **これは違うと思う** | 指摘内容が実態と合わない（フィードバックになります） |
| **参考案をコピーする** | 修正の参考案をクリップボードにコピー |

カードには次の情報が載っています。

- **気になる点**の内容
- **根拠**（なぜ気になるか）
- **修正の参考案**（あくまで参考です）

画面上のセクションは次のとおりです。

1. これから確認
2. あとで確認
3. 違う指摘だった
4. 対応した

開いている指摘（これから確認・あとで）がなくなると、**「今日のWチェックが完了しました」** と表示されます。指摘が0件の場合は **「完了」** で終了できます。

### 人間レビューについて

事業所の設定により、AI結果の公開前に運営側が確認する場合があります。  
その間は「運営が結果を確認しています…」と表示されます。

- 事業所の**管理者**は、必要に応じて **「結果を公開する（運営確認）」** で公開できます
- 設定で **「AIチェック結果の人間レビューをスキップする」** をオンにすると、レビュー待ちを省略できます（管理者のみ）

## 6. あとで確認

メニュー **「あとで確認」** では、「あとで」にした指摘だけを一覧できます。

- 各行から **「結果を開く」** で、元のチェック結果画面に戻れます
- 結果画面で改めて「対応した」などに変更できます

## 7. 期限アラート

> **スタンダード／プレミアム** でご利用いただけます。  
> ライト・未契約の場合はロック画面となり、**「スタンダードを見る」** からプラン確認へ進めます。

### できること

- 同意日・交付日・更新期限・モニタリングなどの期限を登録する
- **超過／7日以内／30日以内／完了** のタブで整理する
- ダッシュボードの「まもなくの期限」にも、残日数付きで表示されます（書類チェック一覧とは別データです）
- 対応が終わったら **「対応した」** にできます
- 期限が近づくと、設定に応じてリマインドメールが届く場合があります

### 期限を追加する

1. **「期限を追加する」** を押します
2. 対象・種類・期限日を入力して保存します

| 種類の例 | 補足 |
|----------|------|
| 同意日 | 利用者・家族の同意に関する日付 |
| 交付日 | 計画書などの交付日 |
| 更新期限 | 計画や契約の更新期限 |
| モニタリング | モニタリング実施の期限 |

画面上の個人名は、プライバシーのため短縮表示されることがあります。

## 8. 突合・矛盾検知（月末の確認）

メニュー **「月末の確認」** から始めます。画面上部で **4大書類の投入状況（検証カバレッジ）** と **矛盾候補一覧** を確認でき、その下のカードから用途別の作業に進めます。

合否・返還は保証しません。未投入のデータは未検証です。

### 8-1. 勤怠・日報を取り込む（介護ソフト連携）

連携方式は **「介護ソフトでCSV書き出し → 本サービスで取込」** です（ソフトへのAPI直結は今後の予定です）。

1. メニュー **「月末の確認」** → **「日報CSVを取り込む」** または **「勤怠・タイムカードCSVを取り込む」**
2. 介護ソフトの種類（汎用／ほのぼの系／カイポケ系／ワイズマン系）を選ぶ
3. CSVをドロップしてプレビューを確認する
4. **「事業所データに取り込む」** で確定する

> 生のCSVファイルはサーバーに保存しません。確定時に必要な項目だけを事業所DBへ登録します。被保険者番号は保存しません。

推奨: 先にヘルパー一覧（職員コード付き）を取り込むと、その後の勤怠・日報の照合精度が上がります。

### 8-2. 勤怠の矛盾を検知する

1. **「月末の確認」** の矛盾候補を見るか、**「勤怠の矛盾を確認する」** を開く
2. 対象期間（開始日・終了日）を指定します
3. **「矛盾を検知する」** を押します
4. 結果テーブルで次の可能性を確認します

| 種類 | 内容 |
|------|------|
| **時間重複** | 同じヘルパーが、同じ日・同じ時間帯に複数の日報を持っている可能性 |
| **打刻と実績の乖離** | タイムカードの退勤時刻より、日報の終了時刻が後になっている可能性 |

断定ではありません。「〜の可能性があります。ご確認ください。」として表示します。

### 8-3. 請求CSVを突合する

国保連へ送る直前の請求CSVを、日報と**1分単位**で照合します。

> **重要**: 請求CSVはサーバーへ送信・保存しません。ブラウザのメモリ上だけでパースし、日報データだけを事業所DBから読み取ります。外部の表計算サービスへの書き出しも行いません。

1. **対象月**を選びます
2. 請求CSVをドロップ（または「CSVを選んで照合する」）
3. 結果テーブルを確認します

| 表示 | 意味 |
|------|------|
| **完全一致**（緑） | 利用者・日付・開始／終了が1分単位で一致 |
| **ずれの可能性／日報なしの可能性**（赤） | 例:「請求: 10:05〜 / 日報: 10:00〜」など。ご確認ください |

想定列名の例: 利用者・日付・サービス提供時間（または開始／終了）

## 10. 設定・同僚の招待・課金

**設定** 画面で次ができます。

### ご契約プラン

- 現在のプラン名を確認できます
- **「プランを確認・変更する」** → 料金ページへ
- **「カード変更・解約する」** → Stripeのお客様ポータル（管理者）

契約直後は「ご契約ありがとうございます」と表示されることがあります。

解約後もこれまでの書類とチェック結果は残りますが、新規チェックはできず **閲覧のみ** になります。再契約は **「プランを選び直す」** から行えます。

### 事業所情報

名称・サービス種別・自治体・ご自身の役割（管理者／スタッフ）を確認できます。

### 同僚を招待する（管理者）

1. **「招待リンクを発行する」** を押します
2. 発行されたリンクを同僚に送ります
3. 同僚は `/invite/…` のページで次のいずれかを行います  
   - アカウントを作成して参加する  
   - ログインして参加する  
   - 招待を受けて参加する  

### ログアウト

**「ログアウトする」** でログアウトし、ログイン画面へ戻ります。

## 11. 料金プラン

表示価格は**税別**です。初期導入費 **50,000円（税別・初回のみ）** が初回契約時に含まれます。  
IT導入補助金のご相談も承ります。

| プラン | 月額（税別） | 主な内容 |
|--------|--------------|----------|
| **ライト** | 19,800円 | 月1回の書類チェック、指摘の確認・対応、閲覧 |
| **スタンダード**（主力プラン） | 29,800円 | 毎日のチェック、期限アラート、指摘対応、閲覧 |
| **プレミアム** | 39,800円 | スタンダードのすべて＋月次レポート（原因分析）＋PDF出力 |

### 契約の流れ

1. 料金ページでプランを選ぶ
2. 管理者として **「このプランで契約する」** を押す
3. Stripeの決済画面でカード情報を入力する
4. 完了後、設定画面に戻ります

### プランによる制限の例

| 状況 | メッセージの例 |
|------|----------------|
| 未契約でチェックしようとする | チェックを始めるにはプランのご契約が必要です… |
| ライトで月の上限に達した | 今月の上限に達しました。スタンダードなら毎日チェックできます |
| アラートが使えない | 期限アラートはスタンダード以上でご利用いただけます |

## 13. 管理者向け：レポート管理

設定から **「レポート管理を開く」**（または `/admin/reports`）で、月次レポートの内容を編集できます。

|------|------|

| 削除 | 論理削除（案内どおり、一定期間後に完全削除） |

## 14. 運営向け：レビューコンソール

サービス運営担当者向けです（`/admin`）。一般の事業所ユーザーには表示されません。

### 主な操作

- 未承認のチェック結果キューを確認する（事業所・書類種別・自治体）
- **そのまま承認**／**修正して承認**／**却下する**
- 「これは違うと思う」フィードバックと対応メモの保存
- 指標：1件あたり平均処理時間・未承認件数・本日処理件数

### キーボードショートカット

| キー | 操作 |
|------|------|
| `J` / `K` | 前後の案件へ移動 |
| `A` | 承認 |
| `R` | 却下 |
| `⌘` + `Enter` | 修正して承認 |

## 15. 運営向け：ルール設定

サービス運営担当者向けです（設定 → **ルール設定**、または `/admin/rules`）。  
中心は **ルールブック**（この自治体ならこれに従う。更新アラート → 人が確認して最新に保つ）です。

構想の正：[ルールブック構想.md](./ルールブック構想.md)

一般の方向けに、**なぜ必要か／何をどこまで設定すればよいか／画面の見かた** をまとめた詳細マニュアルがあります。

→ **[ルール設定 操作マニュアル](./チェック設定ホーム操作マニュアル.md)**

要点だけ先に：

1. ホーム上部の **準備の進み具合** を見る  
2. **次にやること** のボタンだけ押して進める  
3. 必須（自治体・監査項目・承認済み判定ルール・確認待ちゼロ）が揃うと **利用可能**  
4. ルールブックの根拠（参照URL・行政資料）と加算は任意（精度向上）  
5. 「利用可能」＝完璧ではなく、**運用を始められる最低ライン**

## 16. よくある質問

**Q. チェック結果が0件なら、問題なしと見てよいですか？**  
A. いいえ。「見落としを保証するものではありません」。最終判断は貴施設で行ってください。

**Q. パスワードを忘れた場合は？**  
A. 現状、画面からのパスワード再設定は未実装です。運営までお問い合わせください。

**Q. HEIC（iPhoneの写真）は使えますか？**  
A. はい。アップロード時にサーバー側でJPEGへ変換して処理します。

**Q. 解約したらデータは消えますか？**  
A. 解約直後も書類とチェック結果は残り、閲覧できます。新規チェックは再契約が必要です。レポートの削除は論理削除のうえ、案内どおり一定期間後に完全削除されます。

**Q. スマホだけで使えますか？**  
A. はい。撮影からのアップロードを想定した画面構成です。PCでも同じ機能を使えます。

**Q. 「これは違うと思う」は何に使われますか？**  
A. 指摘精度の改善と、運営レビュー時の参考に使います。貴施設の書類が外部に公開されるものではありません。
